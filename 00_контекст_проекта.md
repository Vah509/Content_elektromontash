## 🎯 О проекте
- **Тип:** Корпоративный сайт электромонтажных услуг (B2B).
- **Домен:** `elektromontazh.kiev.ua` (новый), `akcent-el.com.ua` (старый, референс).
- **Цели:** Быстро, красиво, удобно, SEO-оптимизировано.
- **Языки:** 🇺🇦 Украинский (основной) + 🇷🇺 Русский (переключатель).
- **Аудитория:** Промышленные предприятия, строители, частные заказчики (❌ не жилой сектор масс-маркет).

---

## 👤 Пользователь (заказчик)
- Не профессиональный программист, базовое знание WordPress.
- Работает с телефона (Android) и компьютера (Windows).
- Хочет учиться в процессе, но без излишней сложности.
- Предпочитает краткие ответы, без таблиц сравнения, «своими словами».
- Ведёт заметки и копирайтинг в Obsidian (формат `.md`).

## 🛠️ Технический стек (только FREE)
| Компонент | Решение | Примечание |
|-----------|---------|------------|
| **Тема** | `Astra` (основная) | Быстрая, документация, интеграция со Spectra. `Kadence` — альтернатива на тест. |
| **Блоки** | `Spectra` | Визуальный редактор для Gutenberg, без кода. |
| **SEO** | `Rank Math` | Мета-теги, карта сайта, schema, анализ контента. |
| **Языки** | `Polylang` | Связка страниц UA/RU, переключатель в меню, ЧПУ `/ua/`, `/ru/`. |
| **Фото** | `Optimole` | Авто-сжатие, WebP, lazy load, CDN. |
| **Кэш** | `WP Fastest Cache` | Включение кэша одной галочкой. |
| **Формы** | `Spectra Form` (основная) / `Contact Form 7` (резерв) | Визуальный конструктор форм. |
| **Портфолио** | Страницы + Категории + `Spectra Post Grid` | Без CPT/ACF на старте (упрощённо). |
| **Бэкап** | `UpdraftPlus` | Авто-бэкап в Google Drive. |
| **Миграция** | `All-in-One WP Migration` | Перенос с локалки на хостинг. |

## 📐 Правила вёрстки и контента
- **Редактор:** Только Gutenberg + Spectra. Никаких Elementor, WPBakery.
- **HTML-структура:** Чистая, семантическая, проверяется через DevTools.
- **Иерархия заголовков:** Строго `H1 → H2 → H3`.
- **Глобальные блоки:** Шапка/подвал через `Astra → Customize → Header/Footer`. Повторяющиеся секции — как `Reusable Blocks` / `Patterns`.
- **Изображения:** Всегда с `alt`, оптимизация через Optimole.
- **Мобильная адаптация:** Проверка всех блоков на телефоне перед публикацией.

---

## 📁 Правила именования и версионирования
- **Формат:** `vXX_название_на_русском.расширение`
- **Версия:** Двухзначная, увеличивается на `+1` при каждой итерации (`v01` → `v02` → `v03`).
- **Расширения:** 
  - `.md` — текстовые источники, черновики, планы, контекст.
  - `.html` — итоговая вёрстка, экспортируемые фрагменты.
- **Примеры:**
  - `v01_проект_сайт_HTML_вёрстка.md` — технический план.
  - `00_контекст_проекта.md` — этот файл (версия не меняется, только содержание).
  - `v02_структура_главной_страницы.html` — готовая вёрстка.
