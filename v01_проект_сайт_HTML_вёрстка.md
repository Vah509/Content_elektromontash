**Назначение:** Технический план, стек инструментов и правила вёрстки сайта электромонтажных услуг на WordPress. Акцент на чистую HTML-структуру через Gutenberg, бесплатные плагины и простоту поддержки.

---

## 1. 🎯 Цель и ограничения
- **Тип сайта:** Корпоративный B2B-сайт услуг (электромонтаж, щиты, автоматика, портфолио).
- **Приоритеты:** Скорость загрузки, адаптивность, SEO, удобство редактирования (в т.ч. с телефона).
- **Бюджет:** Только бесплатные версии тем и плагинов. Платные функции не требуются.
- **Уровень владения:** Базовый WordPress. Код минимален, упор на визуальные блоки и готовую HTML-структуру.

## 2. 🛠️ Технический стек (Free)
### Тема
- **Основная:** `Astra` (бесплатная). Оптимальная скорость, документация, интеграция с Spectra.
- **Альтернатива:** `Kadence` (бесплатная). Будет протестирована параллельно. Если визуал/удобство понравятся больше — стек переключится на Kadence без потери структуры. *Примечание: обе темы работают по модели freemium, бесплатное ядро остаётся бесплатным навсегда.*

### Плагины
| Плагин | Назначение | Примечание |
|--------|------------|------------|
| `Spectra` | Визуальные блоки Gutenberg (сетки, табы, аккордеоны, формы, галереи) | Основная среда вёрстки |
| `Rank Math SEO` | Мета-теги, карта сайта, schema, SEO-анализ текста | Обязателен для продвижения |
| `Polylang` | Двуязычность (🇺🇦 UA / 🇷🇺 RU), переключатель, ЧПУ | Связывает страницы, не дублирует вручную |
| `Optimole` | Авто-сжатие фото, WebP/AVIF, ленивая загрузка, CDN | Работает «поставил и забыл» |
| `WP Fastest Cache` | Кэш, минификация CSS/JS, ускорение | Одна галочка для активации |
| `UpdraftPlus` | Резервные копии в облако (Google Drive/Dropbox) | Перед правками всегда делать бэкап |
| `All-in-One WP Migration` | Перенос сайта с локального ПК на хостинг | Финальный этап развёртывания |
| `Contact Form 7` | Форма заявок (резерв) | Если Spectra Form не подойдёт |

## 3. 📐 Архитектура HTML-вёрстки (Gutenberg)
Все страницы собираются по единому блочному шаблону. Глобальные блоки (шапка, подвал) настраиваются один раз через `Внешний вид → Настроить → Header/Footer Builder`.

**Типовая структура страницы услуги:**
1. `META` (Title, Description, OG) — Rank Math
2. `H1` — заголовок страницы
3. `Lead` — вводный абзац (УТП, краткая суть)
4. `Services Grid` — сетка услуг (Spectra Info Box / Post Grid)
5. `Process / Why Us` — этапы работы или преимущества (Tabs / Accordion)
6. `Portfolio Preview` — 3-4 последних проекта → ссылка на `/portfolio/`
7. `FAQ` — 4 обязательных вопроса из SEO-требований (Accordion)
8. `CTA / Form` — заявка + загрузка ТЗ (Spectra Form)
9. `Global Footer` — контакты, навигация, копирайт

**Правила вёрстки:**
- Использовать только нативные блоки WordPress и Spectra.
- Стили задавать через `Глобальные стили` темы, избегать инлайн-CSS.
- Иерархия заголовков строго: `H1 → H2 → H3`.
- Все изображения с атрибутом `alt` (Optimole подставляет автоматически).
- Чистая HTML-структура проверяется через `Инструменты разработчика → Элементы`.

## 4. 🌐 Мультиязычность
- Плагин: `Polylang`
- URL: `site.com/ua/...` и `site.com/ru/...`
- В админке: создаёте страницу на UA → нажимаете `+ RU` → создаёте перевод.
- Переключатель языков добавляется в меню через `Языковой переключатель Polylang`.
- Глобальные блоки (шапка/подвал) синхронизируются через настройки плагина.

## 5. 📸 Портфолио и галерея
- **Этап 1 (рекомендуемый для старта):** Обычные страницы проектов + категории. Вывод через `Spectra Post Grid` с фильтрацией по категориям.
- **Этап 2 (при масштабировании):** `CPT UI` + `ACF Free` для кастомных полей.
- Галерея внутри страницы: `Spectra Gallery` (адаптив, лайтбокс, ленивая загрузка).

## 6. 🔄 Рабочий процесс и версионирование
- **Правило именования:** `vXX_название_на_русском.расширение`
- **Версия:** двухзначная, увеличивается на `+1` при каждой новой итерации (`v01` → `v02` → `v03`).
- **Формат:** Текстовые источники/черновики — `.md`, итоговая вёрстка — `.html`.
- **Порядок:** 
  1. Обсуждение → 2. Согласование → 3. Команда «сформируй итоговые файлы» → 4. Генерация → 5. Загрузка в GitHub.
- **Хранение:** Все файлы сохраняются в репозитории `Content_elektromontash`.
