# v01_настройка_формы_перелинковки.md
## 📝 Конфигурация Kadence Form (Вариант 1)
- Поля: Ім'я*(text), Email*(email), Телефон(phone), Назва підприємства(text), Опис/ТЗ(textarea, Default: `Нова заявка`), Файли(file, max 3, 10MB)
- Layout: Stacked (ПК: 2 колонки для первых 4 полей, 📱: 1 колонка)
- Validation: Только обязательные поля. Textarea необязательна.
- Email Notifications: Subject `Нова заявка з сайту | {site_name}`, Body: стандартный шаблон с тегами `{name}`, `{email}`, `{phone}`, `{company}`, `{message}`, `{files}`
- Защита: Honeypot ✅

## 🔗 Стратегия перелинковки «Снизу вверх»
1. Создать страницы-заглушки (Черновики): `Головна`, `Послуги`, `Контакти`
2. В конечных страницах (`ГРЩ`, `Портфоліо`, `Про нас`) ставить ссылки на заглушки через `Link → Existing Page`
3. При публикации главной заменить ссылки на реальные URL
4. Использовать `Anchor Links` для кнопок CTA: `#form-grsh`, `#stats`, `#contacts`
5. Хлебные крошки: Kadence Theme → Breadcrumbs → Enable (авто-генерация путей)
